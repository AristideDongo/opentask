# Projets et tâches

## Projets

Créez un projet depuis la barre latérale (**+** à côté de « Projets »). Un projet peut être rattaché à une [équipe](./collaboration.md#equipes). Chaque projet a ses propres colonnes de Kanban et ses propres tags.

## Tâches

- **Création rapide** : champ en haut du projet, puis Entrée.
- **Création complète** : bouton **Nouvelle tâche** (titre, description, colonne, priorité, personne assignée, échéance, tags), ou **Ajouter** en bas d’une colonne du Kanban.
- **Détail** : cliquez sur le titre d’une tâche pour ouvrir le panneau latéral. L’adresse de la page est partageable.

Champs d’une tâche :

| Champ             | Valeurs                                                            |
| ----------------- | ------------------------------------------------------------------ |
| Colonne           | Une colonne du projet ; son type décide si la tâche est terminée   |
| Priorité          | Basse, normale, haute, urgente                                     |
| Échéance          | Date (une tâche ouverte dont la date est passée est « en retard ») |
| Personne assignée | Un membre du workspace                                             |
| Tags              | Jusqu’à 10 tags du projet                                          |

Le panneau d’une tâche contient aussi ses **pièces jointes** (images et fichiers, par bouton ou glisser-déposer) et ses commentaires, où l’on peut **mentionner** quelqu’un avec `@` : voir [Commentaires, mentions, fichiers et discussion](collaboration.md).

Les **sous-tâches** se créent dans le panneau d’une tâche ; les cocher les déplace dans la première colonne de type « Terminé ».

## Mes tâches

**Mes tâches** regroupe les tâches ouvertes qui vous sont assignées dans le workspace : en retard, aujourd’hui, à venir, sans échéance.
